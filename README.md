# Mechatronik lernen (MTR)

Lernseite für die mündliche Prüfung im Modul Mechatronik: Kapitel zum Lesen, Karteikarten, Drag-and-drop-Übungen und Probeprüfung.

Reine statische Seite ohne Build-Schritt. Für GitHub Pages: Repository-Einstellungen → Pages → Branch `main`, Ordner `/ (root)`.

- `index.html` – Einstieg
- `css/style.css` – Gestaltung
- `js/content-chapters.js` – Kapiteltexte
- `js/content-practice.js` – Karteikarten, Prüfungsfragen, Übungen
- `js/app.js` – Logik

Die Vorlesungs-PDFs sind über `.gitignore` vom Repository ausgeschlossen.
